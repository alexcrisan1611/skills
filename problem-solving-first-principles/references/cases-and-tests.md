# Classification tests and cases

Cycle or event?
- Has it repeated, and on what period? What sits upstream? Does removing the cause stop it? Can you predict the next one?
- The answer may be "event". Record that.
- Genesis 41: God disclosed the cycle (41:16, 25). The test is a human analogy.

Structural or removable?
- Does it return after each fix? Is the cause in the work itself? Do others in the field share it? Does it scale with volume?
- Errors run both ways: calling a defect "structural" excuses it; calling a real cost "fixable" wastes the fix.

Decay or break? (Proverbs 24:30-34)
- At what rate? Since when? Who owned upkeep? Which intervals were missed?

Test of the fix
- Name the loading event before you write the fix. Matthew 7:24-27 and 1 Corinthians 3:11-13 are about Christ: analogy only.

Cases
- Exodus 18:13-26: one person carrying every decision. It needs a written threshold; Jethro's counsel is conditional on God's command (18:23).
- Acts 6:1-4: leaders name what they keep.
- Trials: ask what capacity the failure left behind. Matthew 18:6 is about believers; for a workplace use Ephesians 6:9 and Colossians 4:1.
