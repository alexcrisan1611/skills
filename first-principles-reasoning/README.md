# First Principles Reasoning

A skill that helps you reason from the ground up and find the hidden assumption under a belief before it does damage.

## What it does

Most reasoning copies a known practice. Copying is cheap and usually correct. It fails when the ground under the practice moves. This skill finds what is given before anyone draws a conclusion from it.

A first principle is a claim that nothing more basic can produce. The skill separates three kinds of claim:

- First principle: you cannot reduce it further. You name it and build on it.
- Derived principle: it follows from a first principle. You show the steps.
- Assumption: someone inherited it and never examined it. You test it.

The skill is not an argument for doubt. It finds the floor, tests it, and then builds on it.

The skill rests on Scripture (KJV). Each claim carries one of four labels: "Text states", "Lexical", "Inference", or "Contested". An application of Scripture is always an inference that a fallible reader drew.

## When to use it

Use it when one of these things happens:

- You ask to reason from first principles, or to strip a question back to what is given.
- You want to test whether a claim is true or only repeated.
- An argument rests on authority, fashion, or an analogy.
- Everyone agrees too quickly, and nobody gave a reason.
- People follow a rule, but nobody can say why.
- You ask what something is for.
- You ask what has to be true for a position to hold.

The skill also tells you when not to use it. Use it when the decision is hard to reverse, when a known practice failed, when agreement came too fast, or when the question is about purpose. For other tasks, such as invoicing or password policy, apply the known practice.

## How it works

1. Check the six failure modes. These are the inherited assumption, the substituted authority, the worship of an analogy, the false choice between two options, the unstated premise, and haste.
2. Climb the derivation ladder. It has four rungs: observation, pattern, principle, and axiom (a claim that ends the climb). Each rung rests on the rung below it.
3. Run the tests. The skill uses six verses as tests, for example Acts 17:11 and Proverbs 18:17. Someone who does not profit from the claim tests it, before the decision.
4. Name the condition of the thinker. Fear, sleep, debt, and loyalty shape judgment before reasoning starts.
5. Name the limit. Some questions have no answer from inside the system. The skill says so and acts on what is known.

The answer follows an eight-part shape:

1. The question, in one sentence.
2. What is given, with the uncertain items marked.
3. The load-bearing claim and its label.
4. The derivation, one claim per line.
5. The tests, and who ran them.
6. The falsifier: the observation that ends the argument.
7. The limit: what the answer cannot settle.
8. Confidence, and the cost of being wrong.

For a small question, the skill keeps the answer short.

## What is in this folder

- `SKILL.md`: The main instructions. It defines a first principle, the failure modes, the ladder, the tests, the limits, and the output format.
- `references/method.md`: Two worked climbs of the ladder. One is a business question ("Do we launch a second product?"). One is a personal question ("Why do I keep agreeing to work I cannot finish?"). Each example shows the skipped-rung version beside the full climb. The numbers in the examples are made up.
- `references/epistemic-limits.md`: The limits of the method. It covers Job 38 to 41, Isaiah 55:8-9, Romans 11:33-36, 1 Corinthians 13:9-12, Deuteronomy 29:29, and Ecclesiastes. It ends with a procedure for questions that resist an answer.

## Example prompts

- "Everyone says we need a second product because our competitors have one. Reason this from first principles."
- "What has to be true for this hiring plan to work?"
- "We always do quarterly planning this way. Is there a real reason, or is it habit?"
- "Why do I keep saying yes to work I cannot finish?"

## Limits

- The skill does not give you certainty. It names what it cannot settle.
- Every application of Scripture is an inference, not a statement of the text.
- The skill cannot repair the mind of the person who reasons. It only names that condition as an input.
- It is expensive. It costs time and unsettles settled things. Do not use it on cheap, reversible decisions.
- The supplied Strong's lexicon data has no verse-level tagging. A link from a verse to a Strong's number is a standard concordance association, not a tool finding.
