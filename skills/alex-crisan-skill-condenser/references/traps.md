# Traps: each cost a rerun to find

Text:
- A pointer is not an instruction. "Labels as defined in" another skill: agents dropped the labels. Name the convention inline.
- A cite is an invitation. "See A24" in another skill cost six to nine file reads. Leave it out unless you want the hop.
- Say what a small question gets ("a few lines: open no reference"), or it gets the full format.
- References that cite a source without its text cause second lookups and files opened one by one. Tell agents to open all that apply together and to put all lookups in one command.
- A fix can cause the next failure: "include the surrounding verses" produced a range the script rejects. State the tool's limit beside the instruction.
- A signal needs a tell. "Stay faithful to the text" changes nothing; "you used a parable without first stating its own point" does.
- Drop IDs nothing refers to. Two skills numbering items A1, A2 collide.

Tests:
- Three prompts are narrow coverage. Say so.
- If you rerun only the new arm after a fix, say the old scores are from an earlier batch.
