# Romanian swaps

Short native verbs (Djuvara, Presură, Sebastian, Ilișoi).

| Avoid | Use |
| :--- | :--- |
| *dispune de*, *oferă*, *beneficiază de* | *are*, *e* |
| *gestionezi*, *economisești* | *ții socoteala*, *rămâi cu* |
| *neprezentările*, *simplificate* | *clienții care nu vin*, *(cut)* |
| *am pornit*, *îți scriu înapoi* | *am început*, *îți răspund* |
| *fără card* | *plătești doar dacă îl păstrezi* |
| *fără griji* | *în ritmul tău* |
| *nu-ți face griji*, *nu ezita*, *cu încredere* | *(cut)* |
| *chiar în răspuns la acest mesaj* | *răspunde-mi la acest email* |
| *salvată cu succes*, *creează* | *Gata, e în [loc].*, *trece în [loc]* |
| *Oops!*, *nu a funcționat*, *mai târziu* | *[Ce] nu s-a încheiat. Încearcă [când].* |
| *Ești sigur că vrei să ștergi?* | *Scoți [X]?* / *Ștergi [X]? E definitiv.* |
| *suportul*, *remedierea*, *actualizare* | *mă ocup de clienți*, *îndrepte lucrurile*, *cum stau lucrurile* |
| *problema*, *hiba* | *sursa*, *un blocaj* |
| *Cu drag*, *Echipa X* | *Pace și spor în toate* (`tu`) / *Toate cele bune* (`dvs.`) |

Prefer *ora* to *programarea*, product name to *aplicație*; keep menu words.
