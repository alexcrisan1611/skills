# Romanian swaps

Short native verbs and nouns (Djuvara, Presură, Sebastian, Ilișoi).

| Avoid | Use instead |
| :--- | :--- |
| *gestionezi*, *economisești* | *ții socoteala*, *rămâi cu* |
| *neprezentările*, *simplificate* | *clienții care nu vin*, *(cut)* |
| *am pornit*, *îți scriu înapoi* | *am început*, *îți răspund* |
| *fără card* | *plătești doar dacă vrei să-l păstrezi* |
| *fără griji* | *în ritmul tău* |
| *nu-ți face griji*, *nu ezita*, *cu încredere* | *(cut)* |
| *chiar în răspuns la acest mesaj* | *răspunde-mi la acest email* |
| *salvată cu succes*, *creează* | *Gata, e în [loc].*, *trece în [loc]* |
| *Oops!*, *nu a funcționat*, *mai târziu* | *[Ce] nu s-a încheiat încă. Mai încearcă [când].* |
| *Ești sigur că vrei să ștergi?* | *Scoți [X]?* (revine) / *Ștergi [X]? E definitiv.* |
| *suportul*, *remedierea*, *actualizare* | *mă ocup de clienți*, *îndrepte*, *cum stau lucrurile* |
| *problema*, *hiba* (casual in B2B) | *sursa*, *un blocaj* |
| *Cu drag*, *Echipa X* | *Pace și spor în toate* (`tu`) / *Toate cele bune* (`dvs.`) |

Prefer *ora* to *programarea*, the product's name to *aplicație*; keep menu words.
