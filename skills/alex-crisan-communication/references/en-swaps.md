# English swaps

Short Anglo-Saxon verbs (Orwell, Zinsser, Lewis). No em dashes, rule-of-three, emojis, or *"Not just X, but Y"*. Signal register via greeting, cadence, closing.

| Avoid | Use |
| :--- | :--- |
| *boasts*, *serves as*, *features* (verb) | *has*, *is* |
| *streamline*, *leverage*, *utilize* | *run*, *use*, *help* |
| *seamless*, *effortless*, *empower*, *elevate* | *(cut; state deed)* |
| *We're thrilled/excited!* | *Thank you for trying it.* |
| *no credit card required* | *pay only if you keep it* |
| *worry-free*, *hassle-free*, *stress-free* | *at your own pace* |
| *don't hesitate*, *feel free* | *(cut; invite plainly)* |
| *Saved successfully!*, *Create your first* | *Done. It's on [place].*, *Add your first* |
| *Oops!*, *Something went wrong*, *try again later* | *[Step] did not go through. Try [when].* |
| *Are you sure? Cannot be undone.* | *Remove [X]?* / *Delete [X] permanently?* |
| *inconvenience*, *our technical team*, *remediate*, *keep you updated* | *our mistake*, *[names]*, *fix*, *where things stand* |
| *Thank you for your patience/understanding* | *(cut; name next contact)* |
| *Best, The X Team* | *All the best, [Name]* / *Best regards, [Name]* |
