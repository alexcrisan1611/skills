# Diagnosis: questions and traps

Give these to the user, in order, one at a time.

Location
- When was the output last right? What is the first step where it is wrong?
- Who sees the failure first, and how long after it starts?

Source
- What fed that step: which input, decision or promise?
- Who chose it, and what did they know then?

Act
- What exactly was done or left undone?
- Which rule, target or habit allowed it?

Classification
- Has it happened before, and on what interval?
- If we remove the suspected cause, does it stop?

Test
- What event will next put load here?
- What number would show the fix failed?

Traps
- "Sales is dishonest" is a verdict, not a finding.
- One account is not enough (Proverbs 18:17).
- A blame-shift is recorded, not accepted. Each answers for their own act, then is clothed (Genesis 3:12-21).
- Do not stop at the first cause that fits.
- A second fix for a returning failure is wrong. Reclassify.

Before you deliver the diagnosis, write four observations that would refute it.
